## 题：
### GLTF 为什么适合 Web？
-专为实时/传输设计：JSON + 二进制缓冲，和 WebGL/Three 管线贴合，比 FBX/OBJ 更适合浏览器。
-GLB为单文件二进制，少请求、好缓存、好部署 更稳（是否最快还取决于压缩、CDN、体量）。一样的数据体量加载最快
### 如何优化模型加载？
体积：Draco / meshopt；贴图 KTX2、合理分辨率、少张量。Blender导出gltf模型的时候，可以再导出界面上，勾选压缩，threejs渲染的时候，使用DRACO库解压，使用DRACOloader加载减少模型加载时间；
请求：优先 GLB；能合并就少文件
时机：按需加载、懒加载、别阻塞首屏
运行时：加载后再 traverse 做业务设置，使用traverse递归遍历模型统一设置，减小体积、降带宽；材质/阴影按需，不是为了「加载更快」
